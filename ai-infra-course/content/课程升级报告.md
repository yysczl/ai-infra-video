# 从零认识 AI Infra 课程升级报告

课程保留六章和第五条晚餐请求的首尾呼应。新版共 40 页、364 个教学状态，预计 55 分 7 秒。原版是 29 页、295 个状态，预计 43 分 36 秒。新增 11 分 31 秒主要用于交代模型上线之前的工作、补齐推理前置知识和演示生产排障。新版按约每秒 4.85 个口播计量单位估算，英文术语按发音长度折算，每步另留约 2 秒供换画和观察。实际时长以试录为准。

### 技术复核

- CPU 多核和 SIMD 都能并行。GPU 的 SM、Warp、寄存器和共享内存以 NVIDIA CUDA 为例。算子可拆成多个内核，几个算子也可融合到同一内核。[CUDA 编程模型](https://docs.nvidia.com/cuda/cuda-programming-guide/01-introduction/programming-model.html)
- PagedAttention 在示例里用块表组织和读取设备内存中的 KV。前缀缓存复用已有 KV，还要匹配前缀 Token、相关配置与隔离键。两个独立副本各自维护缓存池，晚餐请求在双副本示例里提前开始，是因为它被分到有空位的副本。[PagedAttention 论文](https://arxiv.org/abs/2309.06180) · [vLLM 前缀缓存设计](https://docs.vllm.ai/en/latest/design/prefix_caching/)
- Llama 3.1 8B 的完整 BF16 KV 为 `2 × 32 × 8 × 128 × 2 = 131,072` 字节/Token，等于 128 KiB。缓存 1,024 个 Token 占 128 MiB，缓存 8,192 个 Token 占 1 GiB。十二条等长序列独立保存时为 12 GiB。以上按原始 KV 数据量计算，权重、临时空间和块管理开销另计。[Meta 模型论文表 3](https://arxiv.org/html/2407.21783)
- FlashAttention 用分块和在线归一化减少中间矩阵的显存往返，仍计算相同的注意力公式。浮点运算次序不同，舍入结果可能有差异。投机解码的收益取决于候选接受率、负载与验证开销。课件里的耗时、占用和并发均为教学示意。[FlashAttention 论文](https://arxiv.org/abs/2205.14135) · [投机解码论文](https://arxiv.org/abs/2211.17192)
- API Server、Scheduler 和 Worker 表示逻辑职责。客户端 TTFT 从发送请求到收到首 Token，可能包含网络与排队。案例中的 TPOT 是首末 Token 到达时间差除以后续间隔数。请求吞吐、Token 吞吐、Goodput 分别按各自的计数口径计算。[vLLM 指标文档](https://docs.vllm.ai/en/latest/design/metrics/) · [DistServe 论文](https://arxiv.org/abs/2401.09670)
